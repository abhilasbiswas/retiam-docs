# Documentation audio fixtures

- `circle-narration.wav`: “A circle moves from left to right.” Generated locally with the macOS Samantha voice; mono PCM at 24 kHz, 1.957625 seconds. Caption timing in the scene is authored, not provider word-boundary metadata.
- `tone.wav`: locally synthesized 440 Hz sine tone, five seconds, with short fades. Used to demonstrate audio analysis, buses and spatial attenuation without a network service.

These fixtures are intentionally frozen so published examples need no speech backend.
